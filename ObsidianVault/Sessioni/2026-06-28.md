# Sessione 2026-06-28 — PPL Quiz (nuovo progetto)

> Lavoro svolto la sera del 27/06 (APK timestampati 21:55) e chiuso il 28/06.

## Richiesta
Creare un'app mobile per allenarsi al **quiz teorico PPL(A)**, veloce, usando il database di quizppl (che online è lento: devi inviare ogni risposta per la correzione). Requisiti: prove d'esame realistiche con i numeri di quesiti per materia; tap sulla risposta → **verde** se giusta e avanza da sola, **rossa** se sbagliata indicando la corretta; **nessuna conferma** ("sei sicuro?", "invia"). Consegna: **APK** in locale + **web app** su `github.com/rdagmr98/ppl`.

## Fatto
- **Database**: estratti **1384 quesiti** del pool ufficiale ENAC/EASA da `tastoeffeuno.it` (quizppl richiede login; tastoeffeuno ha lo stesso pool ed è di libero uso). Scraper `scrape2.ps1` a finestre di 10 ID globali, `-SkipHttpErrorCheck`, decodifica windows-1252, dedup per ID globale. Output → `assets/ppl_quiz.json`.
- **App Flutter** completa (`lib/models.dart`, `builder.dart`, `quiz_screen.dart`, `results_screen.dart`, `main.dart`): 4 modalità (Esame completo 132, Esame+fonia EN 152, Allenamento rapido 30, Studio per materia), feedback istantaneo verde/rosso con auto-advance, esito PROMOSSO/NON PROMOSSO con soglia 75% per materia e revisione errori. Tema scuro Material3.
- **Web app LIVE**: https://rdagmr98.github.io/ppl/ (verificato HTTP 200, title "Quiz PPL(A)"). Deploy via `.github/workflows/deploy.yml` (gh-pages, `force_orphan`); Pages forzato a `build_type=legacy`.
- **APK** `--split-per-abi` → `C:\Users\Gianmarco\Documents\releases\ppl\`: `ppl-quiz-arm64-v8a.apk` (14,8 MB) e `ppl-quiz-armeabi-v7a.apk` (12,3 MB).
- Branding: label app "Quiz PPL", title/manifest web, README, descrizione pubspec.

- MSYS path conversion in Bash (`/ppl/` → `C:/Program Files/Git/ppl/`). Usato il tool PowerShell per i build.
- GitHub Pages 404: `build_type=workflow` → `legacy` + build forzato.
